abstract: >-
  We introduce MEM-SQL, which reuses verified query templates, SQL components, and schema mappings from query history and consults the database schema when memory provides insufficient evidence. On HARE, our benchmark for historical SQL reuse, MEM-SQL raised mean execution accuracy from 37.1% to 50.0% across six language models while reducing input tokens by 76.6% and latency by 68.8% on average relative to direct generation without history.
